# Contributing

Open an issue describing the user problem before proposing a large feature. For code changes, run the checks in README and describe the behavior before/after.

Preserve the server-only IP database, explicit map precision, keyboard access, Chinese and English labels, and reduced-motion support. Do not add paid API dependencies or telemetry by default.

Report incorrect IP records upstream to ip2region. Coordinate matching issues belong here; include the address, data snapshot and expected geographic reference. Do not post personal logs or sensitive IP lists. Report application vulnerabilities privately via [SECURITY.md](SECURITY.md), not public issues.
